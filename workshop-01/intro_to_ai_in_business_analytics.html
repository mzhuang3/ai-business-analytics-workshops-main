Dataset

In this section, we will explore how to deploy AI tools (i.e., LLMs-based agents) to conduct both traditional and machine-learning-based business analytics using data from the Online Retail dataset.

The Online Retail dataset, available from the UCI Machine Learning Repository, contains transactional data from a UK-based online retail store. It is commonly used for data analysis, machine learning, and business intelligence applications such as customer segmentation, sales forecasting, and market basket analysis.

Dataset Overview

  • Source: Transactions from an anonymous UK-based e-commerce store.
  • Time Period: One year (from December 2010 to December 2011).
  • Number of Records: 541,909 transactions.
  • Number of Features: 8 columns describing each transaction.

Features in the Dataset

  • InvoiceNo – Unique identifier for each transaction.
  • StockCode – Product code associated with each item.
  • Description – Name or description of the product.
  • Quantity – Number of items purchased in the transaction.
  • InvoiceDate – Date and time of the transaction.
  • UnitPrice – Price of a single unit of the product (in GBP).
  • CustomerID – Unique identifier for customers (missing for some transactions).
  • Country – Country of the customer making the purchase.

a. RFM Analysis (non-machine-learning)

Key Components of RFM Analysis

  • Recency (R) – How recently a customer made a purchase. Customers who purchased recently are more likely to engage again.
  • Frequency (F) – How often a customer purchases. Frequent buyers are usually more loyal.
  • Monetary (M) – How much a customer spends in total. High spenders contribute more to revenue.

How It Works

  1. Assign scores (e.g., 1–5) to each customer for Recency, Frequency, and Monetary based on their ranking within the dataset.
  2. Combine these scores to classify customers into groups (e.g., VIPs, at-risk customers, inactive customers).
  3. Use these insights for targeted marketing, customer retention, and loyalty programs.

def load_and_prepare_data(file_path):
    """
    Load Excel file and prepare data for RFM analysis.
    """

    # Check for missing values

# Perform RFM analysis
def perform_rfm_analysis(df, analysis_date=None):
    """
    Calculate RFM metrics for each customer.
    """
    # If no analysis date provided, use the max date in the dataset + 1 day
    if analysis_date is None:
        analysis_date = df['InvoiceDate'].max() + timedelta(days=1)
        print(f"Using analysis date: {analysis_date}")

    # Group by CustomerID
    rfm = df.groupby('CustomerID').agg({
        'InvoiceDate': lambda x: (analysis_date - x.max()).days,  # Recency
        'InvoiceNo': 'nunique',  # Frequency
        'TotalValue': 'sum'  # Monetary
    }).reset_index()

    # Rename columns
    rfm.columns = ['CustomerID', 'Recency', 'Frequency', 'Monetary']

    # Add additional metrics
    customer_data = df.groupby('CustomerID').agg({
        'Country': lambda x: x.iloc[0],  # Get the country of the customer
        'StockCode': 'nunique',  # Number of unique products
        'Quantity': 'sum'  # Total quantity
    }).reset_index()

    # Merge with RFM data
    rfm = pd.merge(rfm, customer_data, on='CustomerID')
    rfm.rename(columns={'StockCode': 'UniqueProducts', 'Quantity': 'TotalQuantity'}, inplace=True)

    # Calculate average transaction value
    rfm['AvgTransactionValue'] = rfm['Monetary'] / rfm['Frequency']

    print("\nRFM Metrics Calculated:")
    print(f"- Customers analyzed: {len(rfm)}")
    print(f"- Average Recency: {rfm['Recency'].mean():.2f} days")
    print(f"- Average Frequency: {rfm['Frequency'].mean():.2f} transactions")
    print(f"- Average Monetary: £{rfm['Monetary'].mean():.2f}")

    return rfm

# Create RFM scores
def create_rfm_scores(rfm):
    """
    Create RFM scores and segment customers.
    """
    # Handle potential edge cases where qcut might fail due to duplicates
    # For Recency, lower is better (more recent)
    try:
        rfm['R_Score'] = pd.qcut(rfm['Recency'], 4, labels=[4, 3, 2, 1])
    except ValueError:
        # If pandas.qcut fails due to duplicate values, use rank instead
        rfm['R_Score'] = pd.cut(rfm['Recency'],
                                bins=[rfm['Recency'].min()-1,
                                      rfm['Recency'].quantile(0.25),
                                      rfm['Recency'].quantile(0.5),
                                      rfm['Recency'].quantile(0.75),
                                      rfm['Recency'].max()],
                                labels=[4, 3, 2, 1])

    # For Frequency and Monetary, higher is better
    try:
        rfm['F_Score'] = pd.qcut(rfm['Frequency'], 4, labels=[1, 2, 3, 4])
    except ValueError:
        rfm['F_Score'] = pd.cut(rfm['Frequency'],
                                bins=[rfm['Frequency'].min()-1,
                                      rfm['Frequency'].quantile(0.25),
                                      rfm['Frequency'].quantile(0.5),
                                      rfm['Frequency'].quantile(0.75),
                                      rfm['Frequency'].max()],
                                labels=[1, 2, 3, 4])

    try:
        rfm['M_Score'] = pd.qcut(rfm['Monetary'], 4, labels=[1, 2, 3, 4])
    except ValueError:
        rfm['M_Score'] = pd.cut(rfm['Monetary'],
                                bins=[rfm['Monetary'].min()-1,
                                      rfm['Monetary'].quantile(0.25),
                                      rfm['Monetary'].quantile(0.5),
                                      rfm['Monetary'].quantile(0.75),
                                      rfm['Monetary'].max()],
                                labels=[1, 2, 3, 4])

    # Calculate RFM score
    rfm['RFM_Score'] = rfm['R_Score'].astype(str) + rfm['F_Score'].astype(str) + rfm['M_Score'].astype(str)
    rfm['RFM_Total'] = rfm['R_Score'].astype(int) + rfm['F_Score'].astype(int) + rfm['M_Score'].astype(int)

    print("\nRFM Scoring Complete:")
    print("- R_Score 4 = Most recent customers")
    print("- F_Score 4 = Most frequent customers")
    print("- M_Score 4 = Highest spending customers")

    return rfm

# Assign customer segments
def assign_segments(rfm):
    """
    Assign customers to segments based on RFM scores.
    """
    # Define segments based on RFM scores
    def segment_customer(row):
        r, f, m = row['R_Score'], row['F_Score'], row['M_Score']

        # Convert to int for easier comparison
        r, f, m = int(r), int(f), int(m)

        # Champions: recent, frequent buyers with high spend
        if r >= 4 and (f >= 3 or m >= 3):
            return 'Champions'

        # Loyal Customers: buy regularly with above average spend
        elif (r >= 3) and (f >= 3) and (m >= 3):
            return 'Loyal Customers'

        # Potential Loyalists: recent customers with average frequency
        elif r >= 4 and (f >= 2):
            return 'Potential Loyalists'

        # Promising: recent customers, not frequent yet
        elif r >= 3 and (f <= 2) and (m <= 2):
            return 'Promising'

        # Needs Attention: above average recency, frequency and monetary values
        elif (r >= 2) and (f >= 2) and (m >= 2):
            return 'Needs Attention'

        # At Risk: purchased often but long time ago
        elif (r <= 2) and (f >= 3) and (m >= 3):
            return 'At Risk'

        # Can't Lose: made big purchases and often but haven't returned recently
        elif (r <= 1) and (f >= 4) and (m >= 4):
            return "Can't Lose"

        # Hibernating: low values in all metrics
        elif (r <= 2) and (f <= 2):
            return 'Hibernating'

        # Others
        else:
            return 'Others'

    rfm['Segment'] = rfm.apply(segment_customer, axis=1)

    segment_counts = rfm['Segment'].value_counts()
    print("\nCustomer Segments:")
    for segment, count in segment_counts.items():
        print(f"- {segment}: {count} customers ({count/len(rfm)*100:.2f}%)")

    return rfm

# Analyze segments
def analyze_segments(rfm):
    """
    Analyze characteristics of each segment.
    """
    # Calculate average metrics per segment
    segment_metrics = rfm.groupby('Segment').agg({
        'Recency': 'mean',
        'Frequency': 'mean',
        'Monetary': 'mean',
        'RFM_Total': 'mean',
        'UniqueProducts': 'mean',
        'AvgTransactionValue': 'mean',
        'CustomerID': 'count'
    }).reset_index()

    segment_metrics.rename(columns={'CustomerID': 'Count'}, inplace=True)
    segment_metrics = segment_metrics.sort_values('RFM_Total', ascending=False)

    print("\nSegment Profiles:")
    for _, row in segment_metrics.iterrows():
        print(f"\n{row['Segment']} ({int(row['Count'])} customers):")
        print(f"- Avg Recency: {row['Recency']:.2f} days")
        print(f"- Avg Frequency: {row['Frequency']:.2f} transactions")
        print(f"- Avg Monetary: £{row['Monetary']:.2f}")
        print(f"- Avg RFM Score: {row['RFM_Total']:.2f}")
        print(f"- Avg Unique Products: {row['UniqueProducts']:.2f}")
        print(f"- Avg Transaction Value: £{row['AvgTransactionValue']:.2f}")

    return segment_metrics

b. K-means Clustering (machine-learning-based)

K-Means Clustering is an unsupervised machine learning algorithm used to group similar data points into K clusters. It is widely used in customer segmentation, anomaly detection, and pattern recognition.

How It Works

  1. Choose K (number of clusters).
  2. Randomly initialize K centroids.
  3. Assign each data point to the nearest centroid.
  4. Update centroids based on the mean of assigned points.
  5. Repeat until centroids stabilize or reach a stopping criterion.

Why Use K-Means for Customer Segmentation?

  • Automatically groups customers with similar behaviors.
  • Scalable and efficient for large datasets.
  • Helps identify patterns such as high-value customers, frequent shoppers, or churn risks.

def calculate_customer_features(df, analysis_date=None):
    """
    Calculate features for each customer for clustering.
    """
    # If no analysis date provided, use the max date in the dataset + 1 day
    if analysis_date is None:
        analysis_date = df['InvoiceDate'].max() + timedelta(days=1)
        print(f"Using analysis date: {analysis_date}")

    # RFM features
    rfm = df.groupby('CustomerID').agg({
        'InvoiceDate': lambda x: (analysis_date - x.max()).days,  # Recency
        'InvoiceNo': 'nunique',  # Frequency
        'TotalValue': 'sum'  # Monetary
    }).reset_index()

    # Rename columns
    rfm.columns = ['CustomerID', 'Recency', 'Frequency', 'Monetary']

    # Add additional features
    customer_features = df.groupby('CustomerID').agg({
        'Country': lambda x: x.iloc[0],  # Country
        'StockCode': 'nunique',  # Product variety
        'Quantity': 'sum',  # Total quantity
        'InvoiceDate': ['min', 'max']  # First and last purchase dates
    })

    # Flatten multi-level columns
    customer_features.columns = ['Country', 'UniqueProducts', 'TotalQuantity', 'FirstPurchase', 'LastPurchase']
    customer_features = customer_features.reset_index()

    # Merge with RFM data
    customer_data = pd.merge(rfm, customer_features, on='CustomerID')

    # Calculate additional metrics
    customer_data['AvgOrderValue'] = customer_data['Monetary'] / customer_data['Frequency']
    customer_data['AvgQuantityPerOrder'] = customer_data['TotalQuantity'] / customer_data['Frequency']
    customer_data['AvgUniqueProductsPerOrder'] = customer_data['UniqueProducts'] / customer_data['Frequency']
    customer_data['PurchaseSpan'] = (customer_data['LastPurchase'] - customer_data['FirstPurchase']).dt.days

    # Handle customers with only one purchase (PurchaseSpan = 0)
    customer_data['PurchaseSpan'] = customer_data['PurchaseSpan'].replace(0, 1)

    # Calculate purchase frequency (purchases per day in the active period)
    customer_data['PurchaseFrequency'] = customer_data['Frequency'] / customer_data['PurchaseSpan']

    # Calculate days since first purchase
    customer_data['CustomerAge'] = (analysis_date - customer_data['FirstPurchase']).dt.days

    print("\nCustomer Features Calculated:")
    print(f"- Customers analyzed: {len(customer_data)}")
    print(f"- Features created: {len(customer_data.columns) - 2}")  # Exclude CustomerID and Country

    return customer_data

def prepare_features_for_clustering(customer_data):
    """
    Prepare customer features for clustering by selecting and scaling features.
    """
    # Select features for clustering
    features = [
        'Recency', 'Frequency', 'Monetary',
        'UniqueProducts', 'TotalQuantity',
        'AvgOrderValue', 'AvgQuantityPerOrder', 'AvgUniqueProductsPerOrder',
        'PurchaseFrequency', 'CustomerAge'
    ]

    # Create a copy of the data with selected features
    cluster_data = customer_data[['CustomerID', 'Country'] + features].copy()

    # Remove outliers (optional)
    # Here using simple approach: keep rows where all values are within 3 std of mean
    for feature in features:
        mean = cluster_data[feature].mean()
        std = cluster_data[feature].std()
        cluster_data = cluster_data[
            (cluster_data[feature] <= mean + 3 * std) &
            (cluster_data[feature] >= mean - 3 * std)
        ]

    print(f"\nAfter outlier removal: {len(cluster_data)} customers")

    # Standardize features
    scaler = StandardScaler()
    cluster_data_scaled = scaler.fit_transform(cluster_data[features])

    # Create a DataFrame with scaled values
    cluster_data_scaled_df = pd.DataFrame(
        cluster_data_scaled,
        columns=features,
        index=cluster_data.index
    )

    return cluster_data, cluster_data_scaled_df, features, scaler

def determine_optimal_clusters(data_scaled, max_clusters=10):
    """
    Determine the optimal number of clusters using the elbow method and silhouette score.
    """
    # Calculate inertia (sum of squared distances to closest centroid)
    inertia = []
    silhouette_scores = []

    for n_clusters in range(2, max_clusters + 1):
        kmeans = KMeans(n_clusters=n_clusters, random_state=42, n_init=10)
        kmeans.fit(data_scaled)
        inertia.append(kmeans.inertia_)

        # Calculate silhouette score
        silhouette_avg = silhouette_score(data_scaled, kmeans.labels_)
        silhouette_scores.append(silhouette_avg)

    # Plot elbow method
    plt.figure(figsize=(16, 6))

    plt.subplot(1, 2, 1)
    plt.plot(range(2, max_clusters + 1), inertia, marker='o')
    plt.title('Elbow Method for Optimal Clusters')
    plt.xlabel('Number of Clusters')
    plt.ylabel('Inertia (Sum of Squared Distances)')
    plt.grid(True)

    plt.subplot(1, 2, 2)
    plt.plot(range(2, max_clusters + 1), silhouette_scores, marker='o')
    plt.title('Silhouette Score for Optimal Clusters')
    plt.xlabel('Number of Clusters')
    plt.ylabel('Silhouette Score')
    plt.grid(True)

    plt.tight_layout()
    plt.savefig('figure/optimal_clusters.png', dpi=300)

    # Find optimal number of clusters
    # Simple approach: find the cluster number corresponding to maximum silhouette score
    optimal_clusters = np.argmax(silhouette_scores) + 2  # +2 because we started from 2 clusters

    print(f"\nOptimal number of clusters based on Silhouette Score: {optimal_clusters}")
    print(f"Silhouette Score for {optimal_clusters} clusters: {silhouette_scores[optimal_clusters-2]:.4f}")

    return optimal_clusters

def generate_segment_name(characteristics):
    """
    Generate a meaningful segment name based on characteristics.
    """
    # High-value combination
    if (characteristics['Recency'] in ['Very Recent', 'Recent'] and
        characteristics['Frequency'] in ['Very Frequent', 'Frequent'] and
        characteristics['Monetary'] in ['High Spender']):
        return "VIP Customers"

    # Loyal customers
    elif (characteristics['Recency'] in ['Very Recent', 'Recent'] and
          characteristics['Frequency'] in ['Very Frequent', 'Frequent'] and
          characteristics['Monetary'] in ['Medium Spender']):
        return "Loyal Customers"

    # Big spenders but not frequent
    elif (characteristics['Monetary'] in ['High Spender'] and
          characteristics['Frequency'] in ['Occasional', 'Rare']):
        return "Big Ticket Shoppers"

    # Recent but not frequent or high spend
    elif (characteristics['Recency'] in ['Very Recent', 'Recent'] and
          characteristics['Frequency'] in ['Occasional', 'Rare']):
        return "New or Occasional Customers"

    # Frequent but low spending
    elif (characteristics['Frequency'] in ['Very Frequent', 'Frequent'] and
          characteristics['Monetary'] in ['Low Spender', 'Very Low Spender']):
        return "Frequent Low Spenders"

    # Not recent but previously good customers
    elif (characteristics['Recency'] in ['Not Recent', 'Inactive'] and
          characteristics['Monetary'] in ['High Spender', 'Medium Spender']):
        return "At-Risk High-Value Customers"

    # Not recent and not high value
    elif (characteristics['Recency'] in ['Not Recent', 'Inactive'] and
          characteristics['Monetary'] in ['Low Spender', 'Very Low Spender']):
        return "Churned Customers"

    # Diverse product selection
    elif characteristics['Product Variety'] in ['Very Diverse', 'Diverse']:
        return "Product Explorers"

    # Long-term relationship
    elif characteristics['Customer Age'] in ['Long-term', 'Established']:
        return "Long-term Relationship Customers"

    # Default case
    else:
        return "General Customers"

Customer Purchase Patterns

a. Apriori Algorithm (non-machine-learning)

The Apriori Algorithm is a rule-based approach for market basket analysis, helping businesses understand customer purchase patterns by identifying items frequently bought together. It is widely used in cross-selling, product recommendations, and inventory optimization.

How the Apriori Algorithm Works

  1. Identify Frequent Itemsets
  2. Scan transaction data to find items frequently purchased together based on a minimum support threshold.
  3. Generate Association Rules
  4. Create if-then rules (e.g., If a customer buys A, they are likely to buy B).
  5. Evaluate Rule Strength
  6. Use metrics like Support, Confidence, and Lift to measure rule significance:
    • Support: How often an itemset appears in transactions.
    • Confidence: Likelihood of item B being bought when item A is purchased.
    • Lift: Whether A and B occur together more than expected by chance. > Example Rule: >> “If a customer buys bread and butter, they are 70% likely to also buy milk.”

Why Use Apriori?

  • Simple and interpretable for business decision-making.
  • Improves product bundling and recommendation strategies.
  • Enhances store layout planning to increase sales.

    """
    print(f"Loading data from {file_path}...")
    df = pd.read_excel(file_path)

    print("\nDataset Overview:")
    print(f"- Shape: {df.shape}")
    print(f"- Columns: {', '.join(df.columns)}")

    # Basic data cleaning
    # Remove canceled orders (negative quantities)
    df = df[df['Quantity'] > 0]

    df = df.dropna(subset=['Description', 'StockCode'])

def create_transactions(df):

b. Collaborative Filtering for Product Recommendations (machine-learning-based)

Collaborative Filtering (CF) is a machine learning technique used to provide personalized product recommendations based on customer behavior. It works by analyzing past interactions (e.g., purchases, ratings) to suggest items that a user may like.

How Collaborative Filtering Works

  1. User-Based Collaborative Filtering
    • Finds similar users based on their purchase history.
    • Recommends products that similar users have bought but the target user has not. > Example: “Customers who bought Item A also bought Item B.”
  2. Item-Based Collaborative Filtering
    • Finds similarities between products based on how often they are purchased together.
    • Recommends items that are similar to those a customer has previously bought. > Example: “If you liked Product X, you might like Product Y.”
  3. Matrix Factorization (Advanced CF)
    • Uses algorithms like Singular Value Decomposition (SVD) to predict user preferences.
    • Commonly used in large-scale recommender systems (e.g., Netflix, Amazon).

Why Use Collaborative Filtering?

  • Personalized recommendations improve customer engagement.
  • Scales well for large datasets.
  • Learns from real user behavior, making it more dynamic than rule-based methods like Apriori.

def create_user_item_matrix(customer_item_df, interaction_type='frequency'):
    """
    Create a user-item matrix for collaborative filtering.

    Parameters:
    - customer_item_df: DataFrame with customer-item interactions
    - interaction_type: 'frequency' or 'quantity' to decide which value to use

    Returns:
    - user_item_matrix: Sparse matrix of user-item interactions
    - user_mapper: Dictionary mapping user IDs to matrix indices
    - item_mapper: Dictionary mapping item IDs to matrix indices
    - user_inv_mapper: Dictionary mapping matrix indices to user IDs
    - item_inv_mapper: Dictionary mapping matrix indices to item IDs
    """
    if interaction_type == 'frequency':
        # Use purchase frequency as interaction value
        values = customer_item_df['Frequency']
    else:
        # Use purchased quantity as interaction value
        values = customer_item_df['Quantity']

    # Create mappings of IDs to indices
    unique_customers = customer_item_df['CustomerID'].unique()
    unique_items = customer_item_df['StockCode'].unique()

    user_mapper = {user_id: i for i, user_id in enumerate(unique_customers)}
    item_mapper = {item_id: i for i, item_id in enumerate(unique_items)}

    # Create inverse mappings
    user_inv_mapper = {i: user_id for user_id, i in user_mapper.items()}
    item_inv_mapper = {i: item_id for item_id, i in item_mapper.items()}

    # Create user and item indices
    user_indices = [user_mapper[user_id] for user_id in customer_item_df['CustomerID']]
    item_indices = [item_mapper[item_id] for item_id in customer_item_df['StockCode']]

    # Create sparse matrix
    user_item_matrix = csr_matrix(
        (values, (user_indices, item_indices)),
        shape=(len(unique_customers), len(unique_items))
    )

    print(f"\nUser-Item Matrix Shape: {user_item_matrix.shape}")
    print(f"Matrix density: {user_item_matrix.nnz / (user_item_matrix.shape[0] * user_item_matrix.shape[1]):.6f}")

    return user_item_matrix, user_mapper, item_mapper, user_inv_mapper, item_inv_mapper

def train_svd_model(user_item_matrix, n_components=50):
    """
    Train a simple SVD model for collaborative filtering.
    """
    # Split data for evaluation
    nonzero_indices = user_item_matrix.nonzero()
    nonzero_values = user_item_matrix.data

    # Split indices and values into train and test sets
    train_indices, test_indices = train_test_split(
        range(len(nonzero_values)), test_size=0.2, random_state=42
    )

    # Create train matrix
    train_matrix = csr_matrix(user_item_matrix)
    for i in test_indices:
        row = nonzero_indices[0][i]
        col = nonzero_indices[1][i]
        train_matrix[row, col] = 0

    # Create test data
    test_data = [
        (nonzero_indices[0][i], nonzero_indices[1][i], nonzero_values[i])
        for i in test_indices
    ]

    # Perform SVD on training data
    svd = TruncatedSVD(n_components=n_components, random_state=42)
    user_factors = svd.fit_transform(train_matrix)
    item_factors = svd.components_.T

    # Calculate explained variance
    explained_variance = svd.explained_variance_ratio_.sum()
    print(f"\nSVD Model with {n_components} components:")
    print(f"- Explained variance: {explained_variance:.4f}")

    # Evaluate on test data
    test_predictions = []
    for user, item, rating in test_data:
        pred = np.dot(user_factors[user], item_factors[item])
        test_predictions.append((rating, pred))

    # Calculate RMSE and MAE
    rmse = np.sqrt(np.mean([(true - pred) ** 2 for true, pred in test_predictions]))
    mae = np.mean([abs(true - pred) for true, pred in test_predictions])

    print(f"Model Evaluation:")
    print(f"- RMSE: {rmse:.4f}")
    print(f"- MAE: {mae:.4f}")

    return svd, user_factors, item_factors, test_predictions

def get_recommendations(user_id, user_item_matrix, user_mapper, item_inv_mapper,
                       user_factors, item_factors, df, n=10):
    """
    Get top N product recommendations for a user.
    """
    if user_id not in user_mapper:
        print(f"User {user_id} not found in training data.")
        return pd.DataFrame()

    # Get user index
    user_idx = user_mapper[user_id]

    # Get user vector
    user_vector = user_factors[user_idx]

    # Calculate predicted ratings for all items
    predicted_ratings = np.dot(user_vector, item_factors.T)

    # Get items the user has already interacted with
    user_items = set(user_item_matrix[user_idx].nonzero()[1])

    # Create a list of (item_idx, predicted_rating) tuples for items the user hasn't seen
    predictions = [
        (item_idx, predicted_ratings[item_idx])
        for item_idx in range(len(predicted_ratings))
        if item_idx not in user_items
    ]

    # Sort by predicted rating (descending)
    predictions.sort(key=lambda x: x[1], reverse=True)

    # Get top N recommendations
    top_n_recs = predictions[:n]

    # Convert to DataFrame
    rec_df = pd.DataFrame(top_n_recs, columns=['ItemIdx', 'PredictedRating'])

    # Add item ID
    rec_df['StockCode'] = rec_df['ItemIdx'].apply(lambda x: item_inv_mapper[x])

    # Add product descriptions
    rec_df = pd.merge(
        rec_df,
        df[['StockCode', 'Description']].drop_duplicates(),
        on='StockCode'
    )

    return rec_df[['StockCode', 'Description', 'PredictedRating']]

def get_similar_items(item_id, item_mapper, item_factors, item_inv_mapper, df, n=10):
    """
    Get top N similar items based on learned item factors.
    """
    if item_id not in item_mapper:
        print(f"Item {item_id} not found in training data.")
        return pd.DataFrame()

    # Get item index
    item_idx = item_mapper[item_id]

    # Get item vector
    item_vector = item_factors[item_idx]

    # Calculate similarity to all other items
    similarities = cosine_similarity([item_vector], item_factors)[0]

    # Create a list of (item_idx, similarity) tuples
    item_sims = [
        (idx, sim)
        for idx, sim in enumerate(similarities)
        if idx != item_idx  # Exclude the item itself
    ]

    # Sort by similarity (descending)
    item_sims.sort(key=lambda x: x[1], reverse=True)

    # Get top N similar items
    top_n_sims = item_sims[:n]

    # Convert to DataFrame
    sim_df = pd.DataFrame(top_n_sims, columns=['ItemIdx', 'Similarity'])

    # Add item ID
    sim_df['StockCode'] = sim_df['ItemIdx'].apply(lambda x: item_inv_mapper[x])

    # Add product descriptions
    sim_df = pd.merge(
        sim_df,
        df[['StockCode', 'Description']].drop_duplicates(),
        on='StockCode'
    )

    return sim_df[['StockCode', 'Description', 'Similarity']]

def visualize_latent_factors(svd, df, item_inv_mapper, n_components=3):
    """
    Visualize the latent factors learned by SVD.
    """
    # Get the first n_components of item factors
    item_factors = svd.components_[:n_components].T

    # Get popular items for labeling
    item_popularity = np.asarray(df.groupby('StockCode').size())
    top_items = df.groupby('StockCode').size().sort_values(ascending=False)[:20].index.tolist()

    # Extract factors for visualization
    items_to_plot = []
    labels = []

    for i in range(len(item_inv_mapper)):
        item_id = item_inv_mapper[i]
        if item_id in top_items:
            items_to_plot.append(item_factors[i])

            # Get item description
            desc = df[df['StockCode'] == item_id]['Description'].iloc[0]
            if len(desc) > 15:
                desc = desc[:15] + "..."

            labels.append(desc)

    items_to_plot = np.array(items_to_plot)

    # Create 2D or 3D plot based on components
    if n_components == 2:
        plt.figure(figsize=(12, 10))
        plt.scatter(items_to_plot[:, 0], items_to_plot[:, 1], alpha=0.7)

        # Add labels
        for i, label in enumerate(labels):
            plt.annotate(label, (items_to_plot[i, 0], items_to_plot[i, 1]),
                        xytext=(5, 5), textcoords='offset points', fontsize=9)

        plt.title('Items in Latent Factor Space (2D)', fontsize=14)
        plt.xlabel('Component 1')
        plt.ylabel('Component 2')
        plt.grid(True)

    elif n_components == 3:
        from mpl_toolkits.mplot3d import Axes3D

        fig = plt.figure(figsize=(14, 12))
        ax = fig.add_subplot(111, projection='3d')

        ax.scatter(items_to_plot[:, 0], items_to_plot[:, 1], items_to_plot[:, 2], alpha=0.7)

        # Add labels
        for i, label in enumerate(labels):
            ax.text(items_to_plot[i, 0], items_to_plot[i, 1], items_to_plot[i, 2], label, fontsize=9)

        ax.set_title('Items in Latent Factor Space (3D)', fontsize=14)
        ax.set_xlabel('Component 1')
        ax.set_ylabel('Component 2')
        ax.set_zlabel('Component 3')

    plt.tight_layout()
    plt.savefig(f'figure/latent_factors_{n_components}d.png', dpi=300)
    print(f"Latent factors visualization saved as 'latent_factors_{n_components}d.png'")
